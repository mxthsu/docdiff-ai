# v0.1 — evidence-first comparison

## Problem

Teams frequently compare commercial proposals by hand. Discrepancies in totals,
delivery deadlines, warranty and payment terms are easy to miss.

## In scope

- Compare 2–10 TXT/Markdown documents locally.
- Preserve excerpts and converted-text line numbers for each extracted value.
- Report different, matching, missing and internally contradictory values.
- Offer CLI plus optional Streamlit UI and Docling PDF/Office conversion.
- Offer an optional LLM narrative from existing structured evidence.
- Include synthetic fixtures and deterministic tests.

## Out of scope

- Automatic legal conclusions or contract approval.
- General semantic extraction from arbitrary clauses.
- Guaranteed physical PDF page provenance.
- Public hosting, persistent uploads, production performance claims.

## Next milestones

1. Schema-driven extraction and reusable multilingual rule packs.
2. LLM-assisted extraction with source-evidence verification.
3. Evaluation datasets, negative cases, traces and metrics.
4. Reliable page-coordinate provenance and document highlighting.
5. Public demo with synthetic data and a reviewed security boundary.

## Done means

Offline examples work; tests pass; no mandatory API credentials;
documentation accurately describes scope and limits.
