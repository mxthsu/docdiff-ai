# Document review

Use when changing ingestion, extraction, normalization or report output.

1. Define the field and accepted source formats precisely.
2. Create a synthetic fixture that reproduces the expected behavior.
3. Preserve the exact excerpt and its location for each value.
4. Normalize currencies and units using explicit rules.
5. Report missing and contradictory values without guessing.
6. Verify at least one negative test that prevents false positives.
7. Document limits of rule-based extraction and converted-file locations.

A converted Markdown line is not necessarily a physical PDF page number.
